# SLT5006 UARTプロトコル

[English](protocol.en.md) | 日本語

この資料では、本ライブラリが動作確認と測定に使う通信だけを説明します。レジスタマップ全体、電気定格、保証条件は、SLT5006の最新の製品資料を参照してください。顧客向けに公開されているレジスタ以外にはアクセスしないでください。

## UART設定

| 項目 | 値 |
|---|---|
| ボーレート | 9600 bps |
| データビット | 8 |
| パリティ | なし |
| ストップビット | 1 |
| フロー制御 | なし |
| 接続台数 | 1台 |

フレームに機器アドレス（スレーブID）はなく、先頭バイトが機能コードです。

## フレーム

読出し要求は5バイトです。

```text
01  ADDRESS  SIZE  CRC_H  CRC_L
```

1バイトの書込み要求は6バイトです。

```text
02  ADDRESS  01  DATA  CRC_H  CRC_L
```

正常応答の形式は、読出しと書込みで共通です。書込みの正常応答は、要求をそのまま返します（エコー）。

```text
FUNCTION  ADDRESS  SIZE  DATA[SIZE]  CRC_H  CRC_L
```

エラー応答は4バイトです。

```text
(REQUEST_FUNCTION | 0x80)  ERROR_CODE  CRC_H  CRC_L
```

`SIZE`は1～26バイトで、正常応答は最大31バイトです。改行、終端文字、STX/ETXは付きません。受信側は、先頭バイトのビット7でエラー応答かどうかを判定します。エラー応答でなければ、3バイトのヘッダーから残りの長さを求めます。

## CRC

CRCは、CRC-16/MODBUSと同じパラメータで計算します。

- 初期値: `0xFFFF`
- 反転多項式: `0xA001`
- 各データバイトをXORした後、LSBファーストで8回シフト

ただし、SLT5006は計算した16ビットのCRCを **上位バイト、下位バイト** の順に送信します。下位バイトから送る一般的なMODBUS RTUとは、順序が逆です。

各操作の要求フレーム:

| 操作 | 要求フレーム（16進） |
|---|---|
| ファームウェア読出し | `01 00 03 01 60` |
| シリアル番号読出し | `01 03 04 33 21` |
| 測定開始 | `02 07 01 01 0D 70` |
| 状態読出し | `01 08 01 00 E6` |
| 測定値読出し | `01 11 12 5D AC` |

## センサ情報

| 開始アドレス | サイズ | 内容 |
|---|---:|---|
| `0x00` | 3 | ファームウェアのメジャー、マイナー、リビジョン（各uint8） |
| `0x03` | 4 | シリアル番号（リトルエンディアンのuint32） |

## 測定手順

1. `0x07`に`0x01`を1バイト書き込み、正常なACKが返ることを確認します。
2. ACKを受信してから最初の状態読出しまで、300 ms以上待ちます。
3. `0x08`を1バイト読み、ビット0が1になるまで200 ms間隔で読出しを繰り返します。
4. 開始ACKからの経過時間が既定値の30秒に達したら、新しい状態読出しは始めずに測定タイムアウトとします。個々のUART応答待ちの時間は、この30秒とは別に加算されます。
5. 測定完了後、`0x11`から18バイトを読み出し、測定値に換算して返します。

測定開始の書込みACKは、要求を受け付けたことを示すだけです。測定が完了したかどうかは、手順3で確認します。

## データ形式

複数バイトの値は、すべてリトルエンディアン（下位バイトが先）です。

`0x11`から読み出す18バイト（9ワード）のうち、本ライブラリが公開する値は次のとおりです。

| ワード | 内容 | 換算 |
|---:|---|---|
| 1 | 電源電圧 | 内部ADC値を`raw * 3.3 / 4096 / 0.5` Vで換算し、換算後の電圧だけを公開 |
| 2 | 温度 | 下位12ビットを2の補数として読み、`* 0.0625` degC |
| 3 | Bulk EC | `uint16 * 0.001` dS/m |
| 4 | 体積含水率（ロックウール） | `uint16 * 0.1` % |
| 5 | 体積含水率（一般土壌） | `uint16 * 0.1` % |
| 6 | 体積含水率（ココピート） | `uint16 * 0.1` % |
| 8 | Pore-water EC | `uint16 * 0.001` dS/m |
| 9 | ココピート向けPore EC | `uint16 * 0.001` dS/m |

ココピート向けPore ECは、SLT5006のファームウェア1.7.5以降で使用できます。それより古いファームウェアでも18バイト全体とワード9を読み出せますが、ワード9の値は0です。この0を測定値として扱わないでください。

表にないワードは、本ライブラリでは使用せず、公開もしません。

## センサエラー

| コード | 意味 |
|---:|---|
| `0x01` | 不正な機能コード |
| `0x02` | 不正な開始アドレス |
| `0x03` | 不正なバイト数 |
| `0x04` | 内部受信バッファのオーバーフロー |
| `0x05` | CRC-16エラー |
| `0x06` | 測定中のデータ読出し |
| `0x10` | 内部記憶領域への書込み失敗 |
| `0x20` | センサ内部の通信エラー |
| `0x40` | センサ側の測定タイムアウト |

エラー応答も、CRCと`REQUEST_FUNCTION | 0x80`を検証してからエラーコードを採用します。未知のコードは16進数のまま記録してください。

## 受信側で検証する項目

- 要求の全バイトを書き込めたこと
- 必要なバイト数の応答を、タイムアウト時間内に受信したこと
- 応答の`SIZE`が26以下で、受信バッファに収まること
- CRCが正しいこと
- 正常応答の機能コード、アドレス、サイズが要求と一致すること
- 書込みACKのアドレス、サイズ、データが要求と一致すること（エコー）
- エラー応答の機能コードが`REQUEST_FUNCTION | 0x80`であること

本ライブラリは、これらをすべて検証します。
